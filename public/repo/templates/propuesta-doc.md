## Instrucciones de uso con Qwen

1. Rellena las variables `{{}}` con datos del descubrimiento
2. Pasa el contenido a Qwen con el prompt de "Revisión de propuesta" (Fase 7)
3. Qwen mejora el texto, posicionamiento y argumentario
4. Copia la versión mejorada a Google Docs
5. Comparte con el cliente desde Drive
